Hexadecimal Converter

Encode text to hex or decode hex back to text. Client-side only.

Explanation

Hexadecimal represents each byte as two hex digits (00–ff). It is a compact, human-readable form of binary data.

Example: Hi → 4869

Limitations

  • Auto-detects hex vs text when input looks like even-length hex.
  • Uses BabelCodec src/core encode/decode paths.
