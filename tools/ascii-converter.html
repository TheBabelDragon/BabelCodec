ASCII Converter

Strict ASCII conversion. Characters outside 0–127 are rejected (unlike UTF-8).

Explanation

ASCII is a 7-bit character set (commonly stored in 8-bit bytes 0–127). BabelCodec’s ASCII codec is strict: non-ASCII input raises a validation error.

Example: Hello → hex 48 65 6c 6c 6f
