Hash text with SHA-256 in the browser. Distinct from reversible encodings like Base64.

Encoding vs hashing

SHA-256 is a cryptographic hash function (FIPS 180-4). It maps arbitrary input to a fixed 32-byte digest. Unlike Base64 or hex, hashing is not reversible.

Empty string digest: e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855
