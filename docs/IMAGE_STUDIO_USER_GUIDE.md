# Image Studio User Guide

1. **Playground** — pick a starter or Surprise Me; interpret a prompt locally; plan mutations.
2. **Create** — edit canvas, export SVG/PNG/JPEG/WebP.
3. **Convert** — import images, local edits (grayscale/flip/rotate/undo), export.
4. **Inspect** — metadata and structure; open bytes in Hex.
5. **Batch** — multi-file convert.
6. **Generate** — procedural/mock offline; optional remote gateway.

No API key is required for local work.
